第一部分：游戏策划书
1. 游戏概述
游戏名称：潜艇大作战 / 深海冲浪 (Submarine Race)

游戏类型：直播互动、休闲竞技、派对游戏

核心玩法：观众通过发送弹幕/礼物（对应加减分操作）控制各自的潜艇上浮。最先到达水面（20格）的潜艇获胜。

视觉风格：卡通、深海、色彩明快（参考图片的蓝色渐变背景与彩虹色潜水艇）。

2. 核心机制
垂直赛道：游戏画面分为20个垂直网格（高度）。

初始状态：所有潜水艇位于底部（第0格，水底）。

得分与上浮：每获得1分，潜水艇在垂直方向上浮1格。

胜利条件：潜艇到达第20格（水面/终点线）即为获胜。获胜后该潜艇锁定，不再接受加减分。

扣分机制：若被扣分，潜艇下沉1格。最低沉到第0格（水底），不能变成负数。

操作板：画面底部有每个潜水艇的独立操作面板，包含“+”（加分）和“-”（减分）按钮，以及实时分数显示。

3. 界面与UI设计
游戏主场景：自上而下是蓝天/水面，中间是深海。顶部有一条虚线“FINISH”终点线。水平方向排列8个垂直航道。

潜水艇：使用2D卡通贴图，带有数字编号（如1号、2号），头顶可附带宠物或装饰物（如图片中的企鹅、外星人）。每个潜艇对应一种主色调。

底部控制面板：包含玩家头像、玩家名称、当前分数（如 5/10，表示当前得分与总分上限20）、加号按钮、减号按钮。

反馈效果：

上浮时：潜艇向上移动，伴随水泡粒子特效和引擎声效。

得分时：数字跳动，潜艇闪烁。

获胜时：到达FINISH线，潜艇闪烁金光，弹出胜利特效。

4. 流程设计
准备阶段：初始化8个潜艇（玩家），分数设为0，位置全在水底。

游戏进行中：主播/观众通过点击底部的“+”“-”按钮触发得分事件。系统实时更新各潜艇位置。

游戏结束：任意潜艇到达20分，触发获胜结算。停止所有加减分操作，弹出获胜者名单。

3. 核心脚本与数据结构
全局管理器 GameManager.gd (Autoload)
用于管理游戏状态和分数。

gdscript
extends Node

signal score_changed(player_id: int, new_score: int)

const MAX_SCORE = 20

var player_scores = {
    "Leo": 0, "Lila": 0, "Suzy": 0, "Anna": 0,
    "Elaine": 0, "Felix": 0, "Theo": 0, "Colin": 0, "Alan": 0
}

func add_score(player_name: String, amount: int):
    if not player_scores.has(player_name):
        return
    
    var current_score = player_scores[player_name]
    if current_score >= MAX_SCORE:
        return # 已达终点，不能再增加分数
        
    var new_score = clamp(current_score + amount, 0, MAX_SCORE)
    
    if new_score != current_score:
        player_scores[player_name] = new_score
        score_changed.emit(player_name, new_score)
        
    if new_score == MAX_SCORE:
        _on_player_win(player_name)

func _on_player_win(player_name: String):
    print(player_name + " 获胜！")
    # 触发游戏结束逻辑，停止接收分数
潜艇控制器 Submarine.gd
负责处理位置移动和视觉反馈。

gdscript
extends Node2D

@export var player_name: String = "Leo"
@export var grid_height: float = 40.0 # 每一格的高度（像素）
@export var max_grids: int = 20       # 总格数

@onready var sprite = $Sprite2D
@onready var animation_player = $AnimationPlayer

var current_grid: int = 0 # 当前所在格数 (0-20)
var start_y: float = 0.0

func _ready():
    # 记录初始位置（水底）
    start_y = position.y
    # 连接信号
    GameManager.score_changed.connect(_on_score_changed)

func _on_score_changed(name: String, score: int):
    if name != player_name:
        return
    
    current_grid = score
    _update_position()

func _update_position():
    # 目标位置 = 初始位置 - (当前格数 * 每格高度)
    var target_y = start_y - (current_grid * grid_height)
    
    # 使用Tween实现平滑上浮效果
    var tween = create_tween()
    tween.set_trans(Tween.TRANS_SINE)
    tween.set_ease(Tween.EASE_OUT)
    tween.tween_property(self, "position:y", target_y, 0.5)
    
    # 播放上浮音效/动画
    animation_player.play("float_up")
    if current_grid >= max_grids:
        animation_player.play("win")

4. 关键算法与逻辑
网格计算：
假设整个游戏区域高度为 800px，总格数为 20。
每格高度 grid_height = 800 / 20 = 40px。
潜艇位置公式：Y = 初始Y - (分数 * 40)。
当分数为 20 时，Y = 初始Y - 800，恰好到达顶部终点线。

触发机制（对接直播）：
这部分是直播游戏的核心。在Godot中可以通过 WebSocket 或 HTTP Request 接收来自直播平台（如B站、抖音）的弹幕或礼物数据。

示例：收到“赠送1个小心心” -> 解析出是送给“Leo”的 -> 调用 GameManager.add_score("Leo", 1)。

示例：收到“扣1” -> 解析并调用 GameManager.add_score("Leo", -1)。

5. 美术与动画建议
潜艇动态：不要生硬地移动。使用 Tween 缓动，让潜艇上浮时有一点轻微的“浮动”（左右摇摆或上下弹跳）。

水底氛围：加入背景气泡粒子、水草摇曳动画。

UI反馈：点击加减号时，按钮要有按压效果，且数字旁弹出“+1”或“-1”的飘字。

胜利特效：当潜艇达到第20格，可以让整个屏幕闪烁，潜艇发射烟花，并在潜艇上方显示“WINNER”。

6. 开发注意事项
边界保护：在 GameManager.add_score 中严格使用 clamp 确保分数在 0~20 之间，防止潜艇跑到屏幕外。

性能优化：如果画面中粒子特效过多，建议在潜艇未移动时停止粒子发射。

网络延迟：如果对接直播，所有的加减分操作要加上防抖（Debounce）机制，避免短时间内大量相同的弹幕导致服务器崩溃或画面卡顿。可以在 GameManager 里加一个队列（Queue），按顺序处理得分。

动态生成：图片中有9个潜艇，但名字不同。实际开发时应该将潜艇的名字、颜色、头像做成配置表（JSON或CSV），这样可以随时修改玩家列表，无需修改代码。
